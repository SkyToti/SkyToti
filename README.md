### Cómo trabajo

- **Prueba primero:** cada defecto se reproduce con una prueba que falla antes de corregirlo.
- **Nada se sube sin pruebas:** pruebas y revisión de tipos en verde antes de cada commit, y un candado `pre-push`.
- **Commits chicos**, de un solo tema, y despliegue continuo (Railway, GitHub Actions, Vercel).
- **La documentación se contrasta contra el código**, no contra lo que recuerdo.
